# Project Specification: Online Course Management System (OCMS)

## 1. Project Objective
The Online Course Management System is a centralized web platform for managing the complete online learning lifecycle. It serves students, instructors, and administrators, providing a seamless educational experience from course discovery to certification. The system is designed as a full-stack web application and will serve as the basis for an Object-Oriented Analysis and Design (OOAD) academic project.

## 2. Unique Features (Future Scope)
While not implemented in the initial phase, the architecture will support:
1. Prerequisite-aware course enrollment
2. Skill-gap analysis
3. Smart course recommendations
4. Adaptive learning paths
5. Learning-risk detection
6. Course progress tracking
7. Certificate verification

## 3. Technology Stack
- **Frontend**: Next.js, React, TypeScript, Tailwind CSS, shadcn/ui, TanStack Query, React Hook Form, Zod, Lucide React.
- **Backend**: NestJS, TypeScript, REST API, JWT authentication, Passport, Argon2, class-validator, Swagger/OpenAPI.
- **Database**: PostgreSQL, TypeORM.
- **External Services**: Stripe (Payments), Cloudinary/S3-compatible (Media), Email Notification Service.

## 4. Core Modules
- Authentication & Authorization
- User Management (Student, Instructor, Admin)
- Course & Category Management
- Section & Lesson Management
- Enrollment & Payment Management
- Learning & Progress Management
- Quiz & Assessment Management
- Skill & Recommendation Management
- Certificate Management
- Review Management
- Notification & Analytics/Reporting
- Platform Administration
